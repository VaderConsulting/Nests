# Nests

Chips, Bits and Bytes VB6 Robin (`Robin.exe`, (c) 1998 D. Robinson). Nest/plate drawing searcher over Access `C:\DATA\ACCESS\Nest.MDB` Drawings (nest number, description, grade, thickness, material, drawing), with Nest number / Anywhere search, Browse detail, and Import/Export menus.

**Source last updated:** 1998-06-01 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

_Note: original OneDrive LastWriteTime values were wiped to 2026-08-27 by a zip transfer; date above uses best available evidence (headers/copyright where helpful)._

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `Project1` (`Robin.vbp`) | VB6 | WinForms exe | Robin nest/plate drawing searcher |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `Robin.vbp`

## Requirements

- Visual Basic 6.0 IDE
- Registered OCX/DLL dependencies referenced by the `.vbp` (may need to be installed separately):
  - `DBGRID32.OCX`
  - `comdlg32.ocx`
- DAO 3.5 (`DAO350.DLL`)
